# Security Policy

## Supported version

Security fixes are made for the latest published version.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository when it is available. Do not include exploit details, credentials, or device identifiers in a public issue.

If private reporting is unavailable, open a public issue that only states that you have found a security problem and asks the maintainer for a private contact method.

Include the affected version, the Windows version, the impact, and minimal reproduction steps in the private report. Please allow the maintainer time to investigate before publishing details.
